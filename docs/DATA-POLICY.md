# سياسة بيانات الإنتاج

تُقرأ ملفات `data/` أثناء بناء الموقع وقد تظهر مخرجاتها في الصفحات أو الفهارس العامة. لذلك:

- لا تُحفظ في `data/` ادعاءات أو مصادر أو كيانات وهمية بصيغة توحي بأنها حقيقية أو منشورة.
- يجب أن يرتبط كل ادعاء جوهري بسجل مصدر قابل للفحص.
- توضع بيانات الاختبار الاصطناعية داخل `tests/fixtures/` فقط، مع تسمية واضحة تمنع نشرها.
- لا تُخزَّن هويات المصادر البشرية أو المسودات أو البيانات الشخصية الحساسة في المستودع العام.
- يجب استخدام تواريخ ISO 8601 ومعرفات ثابتة صغيرة الأحرف.
- عند عدم معرفة قيمة، تُستخدم `null` أو يُحذف الحقل وفق الـSchema؛ ولا تُخترع قيمة بديلة.
- أي سجل تجريبي باقٍ لأغراض شرح البنية يجب أن يعلن صراحة أنه قالب، وألا يحمل حالة `published`.

يمنع الدمج عند اكتشاف قيمة اختبار غير معلّمة أو رابط مصدر مختلق داخل بيانات الإنتاج.
