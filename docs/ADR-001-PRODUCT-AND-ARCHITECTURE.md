# ADR-001 — هوية المنتج والمعمارية المرحلية

- **الحالة:** مقبول للمرحلة الحالية
- **التاريخ:** 2026-08-05
- **النطاق:** الموقع العام، المحتوى، البحث، SEO، الأمان والتوسع المستقبلي

## السياق

يحمل المشروع اسم AISearcharab.com، بينما كان التنفيذ الأول يركز على الصحافة الاستقصائية وOSINT. الرؤية الأوسع هي مرصد عربي للبحث والرصد والتحليل في الذكاء الاصطناعي. يوجد خطر في القفز مباشرة إلى Backend وRAG ومدفوعات ولوحة إدارة قبل إثبات جودة المحتوى والبحث التقليدي والتشغيل.

## القرار

1. الاحتفاظ بمعمارية **Static-First باستخدام Hugo** للواجهة العامة والمحتوى الموثق.
2. إعادة تموضع الهوية العامة إلى **مرصد الذكاء الاصطناعي العربي** مع الحفاظ على التحقيق الرقمي وOSINT كقدرات تحريرية ومنهجية.
3. تنفيذ بحث عربي محلي تقليدي أولاً، دون تقديمه كمحرك دلالي أو ذكاء اصطناعي توليدي.
4. عدم إدخال Backend أو قاعدة بيانات أو خدمات ديناميكية حتى توجد حالة استخدام موثقة لا يمكن تنفيذها ثابتاً.
5. فصل أي توسع مستقبلي إلى خدمات مستقلة قابلة للتعطيل، بدلاً من إعادة كتابة الموقع العام.

## الحدود الحالية

المنجز:

- صفحات ثابتة قابلة للفهرسة.
- محتوى منظم ومراجَع عبر Git.
- بحث JSON محلي.
- سجل مصادر وادعاءات وكيانات.
- CI ونشر ثابت.

المؤجل:

- حسابات المستخدمين ولوحة الإدارة.
- البحث المتجهي والهجين.
- RAG والإجابات المولدة.
- المدفوعات والاشتراكات.
- الزحف التلقائي واسع النطاق.
- التخصيص والمؤسسات متعددة المستأجرين.

## شروط الانتقال

لا يبدأ البحث الدلالي قبل:

- إنشاء مجموعة تقييم عربية مراجعة بشرياً.
- قياس البحث التقليدي وتحديد خط أساس.
- اعتماد ميزانية الكلفة والزمن.

لا تبدأ الإجابات المولدة قبل:

- إثبات تحسن البحث الهجين.
- بناء تحقق على مستوى الادعاء والاستشهاد.
- اجتياز اختبارات Prompt Injection وتسميم المصادر.
- وجود fallback غير توليدي وKill Switch.

لا تبدأ المدفوعات قبل:

- اعتماد الكيان القانوني ونوع المنتجات والضرائب والفواتير.
- اختيار مزود واحد وتوثيق PCI scope.
- بناء سجل مالي ومصالحة واختبارات Webhook وIdempotency.

## النتائج الإيجابية

- سطح هجومي وتكلفة تشغيلية أقل.
- أداء وفهرسة أفضل للمحتوى العام.
- فصل واضح بين ما هو موجود وما هو مخطط.
- إمكانية إضافة خدمات ديناميكية دون تعريض المحتوى العام للخطر.

## التكاليف والقيود

- البحث الحالي ليس دلالياً.
- إدارة المحتوى تعتمد على Git وليست CMS للمستخدم غير التقني.
- لا توجد وظائف مخصصة للمستخدمين.
- بعض رؤوس الأمان تعتمد على طبقة الاستضافة/CDN ولا يمكن فرضها من HTML وحده.

## بدائل رُفضت الآن

- إعادة بناء كاملة بـNext.js وFastAPI دون حاجة مثبتة.
- إضافة Microservices منذ البداية.
- تشغيل نموذج لغوي في مسار البحث الأساسي.
- استخدام بيانات تجريبية على أنها محتوى إنتاجي.
