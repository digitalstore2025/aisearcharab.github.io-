# تدقيق AISearcharab.com — 2026-08-05

## القرار

**الحالة الحالية: CONDITIONAL GO للمعاينة والمراجعة، وNO-GO للإطلاق الإنتاجي قبل اجتياز بوابات التحقق المتبقية.**

هذا التقرير يفصل بين ما أمكن فحصه من المستودع وما لم يتوفر له وصول مباشر. لا يعد وجود الكود دليلاً على نجاح النشر أو الأداء الميداني.

## النتائج المؤكدة

### F-001 — بيانات خيالية تحمل صياغة إنتاجية

- **الشدة:** Critical
- **الثقة:** CONFIRMED
- **الأثر:** احتمال نشر ادعاءات ومصادر وأشخاص مختلقين بوصفهم سجلات موثقة.
- **الدليل:** ستة ملفات أضيفت بأسماء `example-*`، بينها ادعاء بحالة `published` ووثيقة حكومية غير حقيقية.
- **الإصلاح:** حُذفت الملفات الستة، وأضيفت سياسة تمنع وضع Fixtures في `data/`، وفحص يمنع ظهور علاماتها في المخرجات.
- **التحقق:** `python scripts/validate_build.py` بعد بناء Hugo.

### F-002 — تعارض هوية المنتج

- **الشدة:** High
- **الثقة:** CONFIRMED
- **الأثر:** النطاق والاسم يوحيان بمنصة بحث ذكاء اصطناعي، بينما الصفحة الرئيسية السابقة تعرض منصة صحافة استقصائية فقط.
- **الإصلاح:** توحيد العلامة باسم «مرصد الذكاء الاصطناعي العربي»، مع الإبقاء على التحقيق وOSINT كمسارات تحريرية. وُثق القرار في ADR.
- **التحقق:** فحص الصفحة الرئيسية والعناوين والوصف وSchema.

### F-003 — نظام بصري غير مطابق للهوية المعتمدة

- **الشدة:** High
- **الثقة:** CONFIRMED
- **الأثر:** ألوان وخطوط عامة، ضعف تميّز العلامة، وعدم اتساق مع النسخة المرئية المعتمدة.
- **الإصلاح:** تطبيق Noto Kufi Arabic وIBM Plex Sans Arabic ولوحة الألوان المؤسسية، وتحسين الاستجابة والتركيز والتباين والبطاقات.
- **القيد:** الخطوط تُحمّل من Google Fonts حالياً؛ الاستضافة المحلية أفضل للخصوصية والاعتمادية وتحتاج ملفات خطوط مرخصة داخل المشروع.

### F-004 — البحث العربي كان مطابقة حرفية سطحية

- **الشدة:** High
- **الثقة:** CONFIRMED
- **الأثر:** فشل الاستعلامات مع التشكيل والتطويل وبعض أشكال الألف والياء، وعدم وجود ترتيب واضح أو رابط قابل للمشاركة.
- **الإصلاح:** تطبيع عربي أساسي، تقسيم الاستعلام، ترتيب حقلي، حد طول، debounce، حالات تحميل وفشل، ودعم `?q=`.
- **القيد:** لا توجد بعد Golden Dataset أو مقاييس Precision/MRR/NDCG؛ لا يجوز وصف البحث بأنه دلالي أو ذكي.

### F-005 — Schema.org موحد لجميع الصفحات

- **الشدة:** Medium
- **الثقة:** CONFIRMED
- **الأثر:** تعريف صفحات القوائم والسياسات والبحث كـArticle، مع بيانات تحريرية ناقصة.
- **الإصلاح:** فصل WebSite وOrganization وArticle وCollectionPage، وإضافة التواريخ والناشر واللغة.
- **التحقق:** تحليل JSON-LD المولد في CI.

### F-006 — بيانات المشاركة وملفات الهوية ناقصة

- **الشدة:** Medium
- **الثقة:** CONFIRMED
- **الأثر:** معاينات اجتماعية ضعيفة وهوية غير مكتملة على الأجهزة.
- **الإصلاح:** إضافة Open Graph وTwitter metadata وfavicon وwebmanifest وtheme color.
- **متبقٍ:** لا توجد صورة Open Graph مخصصة 1200×630؛ يجب تصميم أصل بصري فعلي قبل الإطلاق.

### F-007 — صفحة البحث قابلة للفهرسة رغم قلة محتواها

- **الشدة:** Medium
- **الثقة:** CONFIRMED
- **الأثر:** صفحة رقيقة قد تظهر في نتائج البحث دون قيمة مستقلة.
- **الإصلاح:** `noindex,follow` مع إبقاء روابطها قابلة للتتبع.

### F-008 — مسار الإفصاح الأمني غير مكتمل

- **الشدة:** Medium
- **الثقة:** CONFIRMED
- **الأثر:** احتمال نشر تفاصيل الثغرات في Issues عامة.
- **الإصلاح:** سياسة تفصيلية وملف `/.well-known/security.txt` يوجه إلى Private Vulnerability Reporting.

### F-009 — CI يتحقق من وجود الملفات فقط

- **الشدة:** High
- **الثقة:** CONFIRMED
- **الأثر:** إمكانية نجاح البناء مع JSON-LD معطوب أو بيانات خيالية أو غياب أساسيات SEO.
- **الإصلاح:** إضافة compileall، تحقق المخرجات، تحليل JSON/JSON-LD، فحص العلامة واللغة والاتجاه، منع البيانات الخيالية، وميزانيات ثابتة للحجم.

### F-010 — لا توجد رؤوس أمان قابلة للإثبات

- **الشدة:** Medium
- **الثقة:** POSSIBLE
- **الأثر:** غياب CSP وHSTS وPermissions-Policy وX-Content-Type-Options إذا لم تضفها طبقة الاستضافة.
- **السبب:** GitHub Pages لا يقرأ ملف إعداد رؤوس مخصص من هذا المستودع بالطريقة نفسها التي تفعلها بعض منصات الاستضافة.
- **الإجراء:** التحقق من طبقة CDN/DNS أو الانتقال إلى استضافة تدعم رؤوساً قابلة للضبط. لا تُضف meta CSP قبل اختبار الخطوط وJSON-LD والبحث.

## SEO وGEO وAEO

تم تنفيذ أساس قابل للفحص:

- عنوان ووصف موحدان مع هوية عربية واضحة.
- canonical وrobots وsitemap وRSS.
- بيانات منظمة مرئية وغير مختلقة.
- تواريخ نشر وتحديث ومؤلفون ومصادر وقيود داخل المادة.
- منهجية وتصحيحات وسياسات عامة.
- صفحة بحث غير مفهرسة.

لم يتم التحقق من:

- تغطية الفهرسة الفعلية.
- أخطاء Search Console.
- الروابط الخارجية والداخلية الميتة على الموقع الحي.
- impressions وCTR والكلمات والاستشهادات الفعلية.
- ظهور الموقع في أنظمة AI Search.

لا يوجد ملف أو Schema يضمن الظهور أو الاستشهاد؛ القياس يجب أن يعتمد على بيانات فعلية بعد النشر.

## الأمن والخصوصية

الموقع الحالي ثابت، ولذلك لا تنطبق عليه ثغرات جلسات وقاعدة بيانات ومدفوعات وBOLA في هذه المرحلة. المخاطر الأساسية هي:

- سلسلة توريد GitHub Actions.
- بيانات عامة غير صحيحة أو حساسة.
- XSS من القوالب أو المحتوى إذا فُتح HTML غير الآمن.
- JavaScript للبحث.
- إعدادات النطاق والاستضافة.
- اعتماد الخطوط الخارجية.

الضوابط الموجودة أو المضافة:

- Goldmark unsafe=false.
- لا استخدام لـinnerHTML في البحث.
- URL نتائج البحث محصور في الأصل نفسه.
- CI بصلاحية قراءة للمحتوى.
- Dependabot وCODEOWNERS.
- قناة إفصاح خاصة.
- منع البيانات الوهمية في المخرجات.

## الأداء والإتاحة

تم تحسين:

- CSS ثابت بلا مكتبة واجهة.
- JavaScript محدود للبحث.
- استجابة من 320px فما فوق.
- skip link وfocus-visible وlandmarks وlabels وaria-live.
- reduced motion.
- ميزانيات حجم في CI.

لم يتم إثبات:

- LCP وINP وCLS ميدانياً.
- قارئ شاشة فعلي.
- تباين كل حالة عبر أداة مستقلة.
- تجربة أجهزة حقيقية.
- اختبار Lighthouse من موقع منشور.

## خطة الإغلاق

### قبل دمج Pull Request

1. نجاح CI والبناء والتحقق.
2. مراجعة بشرية للصفحة الرئيسية والبحث والمقالات على 390 و768 و1440 بكسل.
3. التأكد من أن Google Fonts مقبولة، أو استضافتها محلياً.
4. إنشاء صورة Open Graph أصلية.
5. مراجعة النصوص التحريرية والهوية.

### قبل الإطلاق الإنتاجي

1. التحقق من GitHub Pages والنطاق وTLS والتحويل بين www/non-www.
2. فحص رؤوس HTTP الفعلية.
3. ربط Search Console والتحقق من sitemap وindex coverage.
4. تشغيل Lighthouse وaxe واختبار لوحة مفاتيح وقارئ شاشة.
5. اختبار الروابط الخارجية.
6. إجراء Restore drill أو توثيق استعادة المستودع وإعدادات النطاق.
7. تحديد جهة اتصال تحريرية وقانونية وخصوصية واضحة.

### قبل AI Search/RAG

1. Golden Dataset عربية مراجعة بشرياً.
2. baseline ومقاييس جودة.
3. Threat model للـingestion وprompt injection.
4. تحقق استشهادات على مستوى الادعاء.
5. fallback غير توليدي وKill Switch وميزانية تكلفة.

- **المدفوعات وRAG والمصادقة:** NOT_IMPLEMENTED؛ ليست جزءاً من هذا الإصدار ولا يجوز عرضها كقدرات قائمة.
