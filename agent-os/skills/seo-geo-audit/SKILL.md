---
name: seo-geo-audit
description: Audit a public web property for technical SEO, GEO, structured data, and answer-engine discoverability.
---

Use for an actual site/page or a concrete pre-launch web implementation.

- Verify crawl/index fundamentals before content tactics.
- Separate observable technical defects from speculative ranking advice.
- Inspect structured data, canonicalization, internal linking, rendering, performance signals, and source/entity clarity as applicable.
- For GEO/answer engines, prioritize evidence accessibility, stable entity identity, attributable claims, and machine-readable structure over keyword stuffing.
- Use current search-engine/platform documentation for time-sensitive requirements.

Read `references/audit.md` when a full audit is requested.
