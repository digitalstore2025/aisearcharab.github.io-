# SEO/GEO audit reference

Technical: status codes, robots directives, sitemap, canonicals, hreflang, rendering, mobile usability, performance, duplicate URLs.
Structured data: valid applicable schema, consistency with visible content, stable identifiers.
Content/entity: clear authorship, organization/person identity, dates, citations, source provenance, topic coverage, internal links.
Answer-engine readiness: extractable facts, primary evidence, consistent entity naming, accessible pages, concise answer-bearing passages, no fabricated citations.

Do not promise rankings or inclusion in a particular answer engine.
