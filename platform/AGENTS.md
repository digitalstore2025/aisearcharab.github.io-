# Platform Agent Rules

1. لا تدّع وجود RAG أو إجابات مولدة أو حسابات أو مدفوعات ما لم تكن منفذة ومختبرة ومفعلة.
2. لا تدخل بيانات Fixtures إلى قاعدة إنتاج أو محتوى عام.
3. يبدأ البحث بالمعيار المعجمي القابل للقياس؛ أي embeddings أو reranking خلف Feature Flag ومقارنة Golden Dataset.
4. لا fetch خارجي قبل allowlist صريح، وحماية SSRF، وحدود المهلة والحجم وإعادة التوجيه.
5. لا أسرار أو كلمات مرور داخل Git أو Logs أو OpenAPI.
6. كل تغيير في schema يحتاج Alembic migration واختبار upgrade.
7. كل تغيير API يحتاج تحديث OpenAPI contract واختبارات توافق.
8. لا تُسجل الاستعلامات بصيغتها الخام؛ التحليلات اختيارية ومعطلة افتراضياً.
9. لا يُدمج تغيير يفشل في الاختبارات أو يخفض MRR عن 0.85 أو Recall@5 عن 1.0 على مجموعة الاختبار الحالية.
10. تبقى الواجهة العامة Hugo مستقرة حتى وجود خطة ترحيل وRollback معتمدة.
