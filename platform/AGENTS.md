# Platform Agent Rules

1. لا تدّع وجود RAG أو إجابات مولدة أو مدفوعات ما لم تكن منفذة ومختبرة ومفعلة.
2. لا تدخل Fixtures إلى قاعدة إنتاج أو محتوى عام.
3. لا embeddings أو reranking دون Golden Dataset ومقارنة قابلة للإعادة.
4. لا fetch خارجي قبل allowlist وحماية SSRF وحدود المهلة والحجم وإعادة التوجيه.
5. لا أسرار أو كلمات مرور أو session tokens أو CSRF tokens في Git أو Logs أو OpenAPI أو Audit metadata.
6. كل تغيير schema يحتاج Alembic migration واختبار upgrade و`alembic check`.
7. كل تغيير API يحتاج تحديث OpenAPI contract واختبارات توافق.
8. تحليلات البحث معطلة افتراضياً ولا تخزن النص الخام أو IP.
9. لا دمج إذا فشلت الاختبارات أو انخفض MRR عن 0.85 أو Recall@5 عن 1.0 في مجموعة الاختبار الحالية.
10. لا نشر للوحة الإدارة دون HTTPS وSecure cookies ومراجعة CSP وCORS.
11. لا يوجد مستخدم أو كلمة مرور افتراضية؛ المالك الأول عبر Bootstrap تفاعلي فقط.
12. لا تعديل مباشر لمادة منشورة من دور لا يحمل `content:publish`.
13. لا نشر مادة بلا مصدر واحد على الأقل، ولا نشر بوجود ادعاءات ما تزال Draft.
14. تبقى واجهة Hugo قابلة للرجوع إلى الفهرس المحلي عند فشل API.
